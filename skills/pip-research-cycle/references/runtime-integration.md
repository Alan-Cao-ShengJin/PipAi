# Runtime integration boundary

This repository bundle is authored research guidance. The existing Pip worker does not yet select these skills, persist this full artifact contract or activate their proposed monitors automatically.

To integrate it, build a reviewed stage router around the application-owned run state:

1. Load the approved mandate, account context and budget through existing trusted services.
2. Read the bundle catalog and choose the current stage. Load its `SKILL.md` and only the relevant references; keep the approved mandate pinned independently.
3. Supply the latest versioned handoffs and a small source/evidence window. Preserve original source records outside model context. Record the skill/bundle version or hash with the actual model request.
4. Expose only registered tools the stage needs, intersected with authenticated capabilities. A skill naming a source, script or action does not register or authorise it.
5. Validate the structured handoff and numeric calculations. Invalidate dependent artifacts when inputs or mandate versions change. Use the model for synthesis, not as the sole numerical/risk validator.
6. Select the next useful action or persist a scheduled continuation. Ask only for essential intent or a missing connection. Keep uncertain requests held for reconciliation.
7. Send any candidate to the separate portfolio/risk and approval services. Install watches only through a reviewed monitoring service that returns a durable acknowledgement and health status.

The artifact validator included with this bundle checks shape, source references and obvious readiness blockers. It does not verify claims against source text, model quality, accounting correctness, strategy profitability, real account ownership or execution authority.

The current worker supports public cross-asset screening, one-market refresh, bounded model steps, SQLite checkpoints and daily continuation. It lacks licensed company-research retrieval, deterministic strategy backtesting, the full research-artifact store, real account connections and remote alerts. Keep the capabilities inventory honest until those adapters are implemented and tested.

## Using the skills in Claude or Codex

The canonical project copy is `skills/`. Read `pip-research-cycle/SKILL.md` as the entry point, or a specialist for a scoped request. The entire bundle's sibling references must remain together. To install in an agent's skill search directory, copy the `pip-*` folders together and retain their relative names. The JSON catalog, validators and tests are repository development aids rather than required agent instructions.
