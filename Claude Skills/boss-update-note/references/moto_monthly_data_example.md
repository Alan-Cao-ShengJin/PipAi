# 致郄总：250cc以上出口及隆鑫（2026-10-22）— 草稿 v2（只保留出口和隆鑫）

> 来源：国联民生摩托车行业基础数据库20261021（中国摩托车商会；行业250cc以上总量取“核心数据汇总”页）；三家数据取自摩托车三公司_月度出口内销_更新至26年9月.xlsx。国联没有到9月的行业250cc以上出口数据，出口只比较三家。

郄总，简单汇总一下250cc以上的出口和隆鑫。

出口方面，三季度隆鑫增长最快，同比+46%，9月单月+66%；春风三季度+24%，9月+53%；钱江三季度+14%，9月−13%。1–9月三家出口都在20%左右：隆鑫+24%、钱江+22%、春风+16%。

隆鑫250cc以上（出口+内销合计）三季度5.13万辆，同比+27%：其中出口3.01万辆，同比+46%，内销2.12万辆，只增长8%，所以合计增速被内销拉低。1–9月合计同比+26%，是三家里累计增长最好的，行业份额从去年同期的14.2%提到16.0%。9月销量1.60万辆，同比+33%，增长基本都来自出口：出口1.23万辆，占比约76%；内销3,786辆，同比−19%，比8月的8,687辆明显回落。结构上250–400cc出口7,845辆，是去年同期的3倍，从5月的2,769辆一路上升。
